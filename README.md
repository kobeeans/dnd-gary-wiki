# D&D Rules & Homebrew

A static, GitHub Pages-friendly D&D rules reference generated from the attached SRD 5.2.1 PDF.

## Features
- Full extracted SRD text indexed by source page
- Section navigation
- Client-side search
- Homebrew page creator/editor
- Homebrew stored in browser `localStorage`
- Homebrew JSON export/import
- No server required

## Run locally
Because browsers can block `fetch()` when opening `index.html` directly, serve the folder with any static server, for example:

```bash
python -m http.server
```

Then open the local address shown by Python.

## GitHub Pages
Upload the contents of this folder to a GitHub repository and enable GitHub Pages from the repository's Settings > Pages. Use the repository root as the publishing source.
